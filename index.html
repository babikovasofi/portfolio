Cubr — дуэли по спидкубингу, где судья — камера

cubr-game.ru GitHub

Веб-сервис для соревнований по сборке кубика Рубика. Игрок собирает кубик перед веб-камерой, браузер распознаёт грани и состояние кубика, ловит старт и стоп по рукам — так компьютерное зрение заменяет судью. Видео не уходит с устройства, на сервер отправляется только результат.

  • Режимы: соло-тренировка, онлайн-дуэли с синхронным стартом, турнир недели, скрамбл дня, тренажёр на 78 случаев OLL/PLL.
  • Рейтинг-кубки с защитой от фарма, профиль с рекордами и бейджами, друзья и чат, интерфейс на RU/EN.
  • Стек: React 19 + TypeScript + Vite, MediaPipe Hands и свои модули распознавания цвета; FastAPI + PostgreSQL; деплой на VPS в Docker, CI на GitHub Actions.

КосмоХакатон «Кадры для космоса» 5 место

11–13.09.2026 · Благовещенск, АмГУ

Окружной этап всероссийской серии хакатонов федерального проекта «Кадры для космоса» (6 этапов по России, финал в Москве, призовой фонд 7,2 млн ₽). Задачи космической отрасли. Команда заняла 5 место.

Проект: HydroWatch Амур — сервис оперативного мониторинга паводков на Амуре по спутниковым снимкам Sentinel-1 (радар) и Sentinel-2 (оптика). Команда: я и Иван Рябченко.

  • Проблема: пик паводка приходит вместе с облаками, оптика бесполезна — перешли на радар, он видит сквозь облака.
  • ML-пайплайн: спекл-фильтр → адаптивный порог по тайлам → очистка (уклон, застройка, HAND) → маска затопления и площади в гектарах.
  • Метрика выросла с 0,43 до 0,60 при потолке 0,74; расчёт 11 пар за 29 с на обычном процессоре, без GPU.
  • Веб-интерфейс: карта со шторкой «до / пик», слои воды и сводный отчёт по району.

Data Match Финалист

Осень 2026 · Омск · ХК «Авангард»

Первый хоккейный хакатон по аналитике данных в спорте на реальных данных ХК «Авангард». Финалист технического трека — прошла в финал из всех участников онлайн-этапа.

Проект: прогноз спроса на билеты домашних матчей ХК «Авангард» по 8 ценовым зонам (команда из 2 человек, с Иваном Рябченко).

  • Модель: оценка по истории + поправка на темп продаж + потолок заполнения; отдельная логика для праздничных матчей.
  • Проверка честным бэктестом: 51 временной срез, 5 848 пар «матч × зона».
  • Результат: ошибка (RMSE) на 17 % ниже базового прогноза, а когда продажи уже идут — на 36 % ниже.
  • Дали клубу рекомендации: что менять в продажах и какие данные собирать.
